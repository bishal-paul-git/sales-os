# End-to-end sales playbook

| Stage | Owner role | Required output | Exit condition |
| --- | --- | --- | --- |
| Campaign brief | Sales Manager | Market, segment, offer hypothesis, cap, goal | Owner brief recorded |
| Research | Partner Researcher | Sourced company profile | Relevant partner fit established |
| Qualification | Contact Qualifier | Contact/entity/email/conflict evidence | Draft gate passes |
| Drafting | Outreach Writer | Initial and follow-up drafts | Review passes |
| Approval | Sales Manager | Exact recipient, sender and revision | Owner approves and send gates pass |
| Outreach | Pipeline Manager | Reconciled provider event | Confirmed provider ID, or unknown held |
| Conversation | Deal Advisor | Reply classification and response draft | Next action agreed |
| Discovery/demo | Deal Advisor | Requirements and demo brief | Mutual fit confirmed |
| Proposal | Deal Advisor | Scoped approved commercial proposal | Customer decision documented |
| Won/handover | Sales Manager | Accepted agreement and delivery handover | Implementation accepts |
| Learning | Pipeline Manager | Funnel report and improvement | Next experiment defined |

Use qualification.md, messaging.md and deals.md for detailed procedures. The pre-send stage is mandatory for every message, including replies and follow-ups. The owner can approve a bounded lane, but unrecorded approval is not assumed.

## First pilot

Start with five existing high-fit candidates, not a fresh scrape. Revalidate evidence, resolve decision ownership and verify contacts. Produce five fully sourced drafts. The owner reviews the actual content, partner proposition and sender. Send only after explicit approval with a verified connected sender and private event store. Review outcomes before expansion.

## Learning loop

Run one segment/offer experiment at a time. Record hypothesis, message revision, target count, cost and observation window. Compare human replies, relevant conversations and qualified opportunities. Small batches are directional; never present them as statistically proven improvements. Improve targeting before increasing volume.
