# Agent operating instructions

Work only on Erudience sales. Do not mix in Absolute Intelligence UK client records, proof, pricing or contacts. Load knowledge/business.md, memory/current-state.md and config/run-control.json first.

The owner authorises creating and maintaining this system in bishal-paul-git/sales-os. Research and draft preparation are allowed. Sending messages, booking on another person's behalf, spending, enrolling contacts and committing commercial terms need an explicit recorded owner instruction for that action or lane. Account access is not approval.

Use agents/sales-manager.md to route specialist roles. Run writer, review and execution as distinct stages even when one assistant performs them. Do not claim separate agents ran unless they actually did.

Prioritise completing qualified existing records before collecting large batches. Target decision-makers at partner companies serving multiple potential customers. Generic mailboxes are contact routes, not named decision-maker addresses. Do not guess personal emails or equate website publication with technical verification.

Separate verified fact, source-reported fact, owner statement, inference and unknown. Record source and date for material claims. Never invent results, clients, guarantees, partnerships, email verification or tool execution.

Keep private CRM data, correspondence, contracts, margins, secrets and contact exports out of this public repository. Sanitise evidence and use synthetic fixtures. Never add client names or proof without permission to attribute them to Erudience.

Before external execution: recheck suppression, exact recipient, approved content revision, verified contact route, campaign permissions and duplicate key. After execution: retain remote ID and reconcile outcome. An ambiguous timeout means UNKNOWN, not failed; inspect provider state before retrying.

Finish each run with completed work, evidence, blocked items, next owner action and private memory updates. Change public instructions only when behaviour or an approved decision changes; do not leak private event history into Git.
