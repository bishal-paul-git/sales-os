# Shared agent registry

| Role | Shared responsibility | Business context supplied separately |
| --- | --- | --- |
| [Sales Manager](sales-manager.md) | Prioritise, route and review | Objective, offer, owner and constraints |
| [Partner Researcher](partner-researcher.md) | Source partner-company evidence | ICP and target market; use only for partner campaigns |
| [Contact Qualifier](contact-qualifier.md) | Verify contacts and eligibility | Campaign type and relationship basis |
| [Outreach Writer](outreach-writer.md) | Write specific emails and follow-ups | Audience, brand, approved claims and selected sequence |
| [Deal Advisor](deal-advisor.md) | Replies, discovery and proposals | Approved capabilities and commercial terms |
| [Pipeline Manager](pipeline-manager.md) | Events, tasks and reporting | Private CRM namespace and business sender |

For opt-in/lifecycle campaigns, Researcher researches audience needs rather than scraping new recipients. Qualifier applies policies/email-eligibility.md; company/ABN checks are partner-campaign gates, not universal subscriber gates. Writer uses the selected campaign's cadence instead of assuming cold follow-ups. Pipeline Manager tracks campaign delivery and subscriptions as well as opportunities. Roles run sequentially in one assistant unless separate execution is explicitly requested.
